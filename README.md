# B'more Tech Hackathon

Landing page for the B'more Tech Hackathon, Dec 10, Digital Harbor Tech Lab, Baltimore. Sponsored by Knucklepuck.

Live at https://www.baltimorehackathon.com. Pushes to `main` deploy to production on Vercel.

## Files
- `index.html`: the whole page (plain HTML, CSS and a little JS). Edit it directly. Rebuilt by hand from the design handoff on 2026-11-23 to add share meta tags, JSON-LD (Event, FAQPage), a FAQ section and mobile fixes.
- `assets/`: web-sized logo, RSVP QR code and flyer preview.
- `exports/BMore-Tech-Hackathon-Flyer.png`: full-size flyer for the download link.
- `og-image.png`: 1200x630 link-share image. `favicon.svg`, `robots.txt`, `sitemap.xml`.

If you change event facts or FAQ answers, update the JSON-LD block in the `<head>` to match.
